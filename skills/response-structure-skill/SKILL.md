# RFP Response Structure

## Common Sections

1. Company overview
2. Product capability answers
3. Security and compliance
4. Implementation and support
5. Commercial or procurement notes

## Drafting Pattern

- Short answer first
- Supporting detail second
- Caveat or assumption last when needed
