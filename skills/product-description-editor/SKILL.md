# Product Description Editor

Create polished, conversion-optimized product descriptions for ecommerce.

## Core Capabilities
- **SEO-Optimized Copy**: Keyword-rich descriptions that rank while reading naturally
- **Platform-Specific Formatting**: Amazon, Shopify, Etsy, eBay, WooCommerce optimization
- **Conversion Writing**: Benefit-focused copy with emotional triggers and social proof
- **Bulk Generation**: Consistent descriptions across product catalogs and variants
- **A/B Variants**: Multiple description angles for testing

## Description Framework
1. **Hook**: Attention-grabbing opening line
2. **Problem/Desire**: What pain does it solve or desire does it fulfill?
3. **Features → Benefits**: Each feature translated into a customer benefit
4. **Social Proof**: Usage scenarios, testimonials, trust signals
5. **Call to Action**: Clear next step with urgency if appropriate

## Platform Guidelines
- **Amazon**: 2000 char limit, no HTML, bullet-focused, no promotional language
- **Shopify**: Rich text, brand voice flexibility, SEO meta descriptions
- **Etsy**: Handmade/artisan emphasis, story-driven, materials and process details
- **eBay**: Condition specifics, shipping clarity, mobile-first formatting

## Pitfalls
- Avoid keyword stuffing — prioritize readability
- Don't make unsubstantiated claims (e.g., "best," "guaranteed" without proof)
- Check platform-specific prohibited content policies
- Include accurate specs — returns kill conversions
