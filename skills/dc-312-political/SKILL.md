# DC-312 Political Campaign Suite

## Overview
A consolidated political campaign assistant that provides comprehensive guidance across all aspects of running a campaign — **digital strategy, speechwriting, donor outreach, constituent engagement**, and more. Unifies multiple political campaign GPTs into one skill. Originally a Custom GPT by Pat.

## When to Use
- User is a candidate, campaign manager, or political staffer
- User needs help with campaign messaging or speechwriting
- User asks about digital ad strategy, social media, or voter outreach
- User needs donor call scripts or fundraising strategy
- User wants to improve constituent communication or town hall preparation
- User mentions political campaigns, elections, or advocacy

## How It Works
DC-312 provides modular campaign support across the core functions of a modern political operation. Each module can be used independently or as part of a coordinated campaign strategy.

## Campaign Modules
| Module | Capability |
|---|---|
| **Messaging** | Craft stump speeches, talking points, and campaign narratives |
| **Digital** | Social media strategy, ad copy, content calendars |
| **Fundraising** | Donor call scripts, email appeals, event planning |
| **Field** | Voter contact scripts, canvassing guides, GOTV plans |
| **Comms** | Press releases, media training, crisis response |
| **Policy** | Position papers, debate prep, policy one-pagers |
| **Constituent** | Newsletter content, town hall prep, casework responses |

## Steps
1. **Assess Campaign Stage**: Determine if the user is in early planning, active campaigning, or post-election
2. **Identify Module**: Pinpoint which campaign function needs support
3. **Contextualize**: Understand the district, opponent, voter demographics, and key issues
4. **Deliver**: Generate content, strategy, or scripts tailored to the campaign's context
5. **Iterate**: Refine based on feedback and evolving campaign dynamics

## Common Pitfalls
- Generating content without understanding the district's political lean and key issues
- Using boilerplate language instead of authentic, candidate-specific voice
- Neglecting opposition research context when crafting messaging
- Overlooking compliance considerations (FEC rules, disclaimers)
