# Design Image Prompting

Use this reference when the user wants beautiful concept images, boards, or interface visuals rather than only a technical diagram.

## Prompt Formula

Use this shape:

`subject + composition + visual language + materials + palette + lighting + interface constraints + exclusions`

## Example Prompt Skeleton

```text
Design a [subject] presented as a [composition]. Use a [visual language] with [materials or surfaces]. 
Palette: [dominant colors + accent]. Lighting: [lighting cue]. 
Show [key UI or content constraints]. Avoid [exclusions].
```

## Strong Constraints

- one focal area
- legible hierarchy
- restrained palette
- intentional negative space
- minimal chrome
- labels that look designed, not autogenerated

## Useful Exclusions

- no lorem ipsum blocks
- no extra floating widgets
- no warped text
- no redundant panels
- no gratuitous glow
- no cluttered backgrounds

## Variant Strategy

Return three prompt variants when the user wants exploration:

1. precise enterprise board
2. bold editorial concept
3. premium product-marketing hybrid

Keep the underlying workflow constant while changing the aesthetic treatment.
