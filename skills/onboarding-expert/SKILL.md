# Onboarding Expert

## Overview
Designs structured client onboarding flows that translate a sales enablement plan into a seamless, systematic client experience. Ensures new clients go from signed contract to active, happy users with minimal friction.

## When to Use
- Designing a new client onboarding program from scratch
- Improving an existing onboarding flow with high churn or low activation rates
- Translating a Sales Enablement Plan into a client-facing implementation roadmap
- Building onboarding checklists, milestone trackers, and communication cadences
- Creating self-serve onboarding resources (knowledge base, video library, interactive guides)
- Designing handoff processes between Sales → Onboarding → Customer Success

## How It Works
1. Start with the client's desired outcome (the "why" behind their purchase).
2. Map the journey: kickoff → setup → first value → adoption → expansion.
3. Design touchpoints, milestones, and resources at each stage.
4. Build accountability: clear owner per stage, SLAs, escalation paths.
5. Measure onboarding health: time-to-first-value, activation rate, NPS at 30/60/90 days.

## Steps
1. **Outcome definition** — Clarify what success looks like for the client (not just "go live" — the business outcome).
2. **Journey mapping** — Define phases (kickoff, configuration, training, go-live, optimization) with milestones per phase.
3. **Role assignment** — Identify who owns each phase: implementation manager, CSM, support, client champion.
4. **Communication plan** — Set cadence: weekly check-ins, milestone reviews, executive sponsor touchpoints.
5. **Resource creation** — Build onboarding guides, video walkthroughs, setup checklists, and FAQ docs.
6. **Risk detection** — Define leading indicators of at-risk onboardings (missed milestones, low engagement, unanswered questions).
7. **Success metrics** — Define and track: time-to-first-value, activation completion rate, 30-day health score.

## Common Pitfalls
- **One-size-fits-all**: A SMB client and enterprise client need different onboarding depth. Segment your flows.
- **No client accountability**: Onboarding requires client effort. Set expectations early with a shared project plan.
- **Skipping the warm handoff**: The Sales-to-Onboarding transition is the #1 point of friction. Never let it be a cold email.
- **Feature-dumping**: Teaching every feature at once overwhelms. Focus on the minimum path to first value.
- **No feedback loop**: Run post-onboarding surveys and feed insights back into the sales enablement plan.
